## 場景 1：光復南路車禍 (ACC_001)

### 事件摘要
- **事件類型**: 車禍 + 路障
- **位置**: 光復南路（近松山高中前）
- **時間**: 2026-07-24 17:15（下班尖峰）
- **持續時間**: 預估 40 分鐘

### 觸發條件
| 條件 | 值 | 是否觸發 |
|------|-----|----------|
| ACCIDENTS | >= 2 | ✅ (假設 >= 2) |
| OBSTACLES | >= 1 | ✅ (假設 >= 1) |
| CONGESTION | > 0.85 | ✅ (假設 > 0.85) |

### Demo 流程

```
時間軸
│
├─ 17:00  正常狀態
│         → 儀表板顯示綠色，無預警
│
├─ 17:15  事件發生
│         → 系統自動偵測到 ACC_001
│         → 畫面跳出紅色警報
│         → 60 秒倒數計時開始
│
├─ 17:15:30  決策完成
│         → 儀表板更新：
│           • 光復南路顯示紅色（A 級）
│           • 鄰近路段顯示黃色（B 級）
│         → 右側出現決策建議書
│
├─ 17:16  疏散路徑顯示
│         → 地圖上顯示主疏散路徑（紅色箭頭）
│         → 地圖上次疏散路徑（藍色箭頭）
│         → 路徑旁標註排除原因
│
├─ 17:17  多語通報
│         → 系統自動產出中英日韓 4 種語言警示
│         → 點擊「一鍵發布」按鈕
│         → 模擬發送成功
│
└─ 17:20  What-if 模擬
          → 指揮官輸入：「如果改走建國高架呢？」
          → 系統回答：不建議，因為容量不足
          → 引用 SOP 第 2 條
```

### 預期回應文案

#### AI 決策建議書
```
【事件】光復南路車禍 + 路障
【級別】A 級（嚴重）
【時間】2026-07-24 17:15
【預估恢復】40 分鐘

【處置建議】
1. 啟動 SOP-2 車禍與路障應變
2. 主疏散路徑：忠孝東路（南向北）
3. 次疏散路徑：南京東路（東向西）
4. 排除路段：建國高架（容量不足 1000）
5. 連絡北捷：加強忠孝復興站疏散

【判定依據】
- ACCIDENTS >= 2 → 觸發車禍應變
- OBSTACLES >= 1 → 觸發路障應變
- CONGESTION > 0.85 → 交通壅塞
```

## Demo 腳本

### 開場（30 秒）
「各位評審好，我們是城市交通應變 AI 指揮台團隊。今天要展示的是，當城市發生交通突發事件時，我們的系統如何在 60 秒內協助指揮官做出可靠決策。」

### 場景 1（2 分鐘）
「首先，我們模擬光復南路發生車禍。系統自動偵測到事件，60 秒內完成路網重規劃，產出疏散路徑建議和多語通報。」

### 場景 2（1 分鐘）
「接下來，捷運小巨蛋站人流異常成長。系統自動觸發接駁疏散建議，並產出中英日韓通報。」

### 場景 3（1 分鐘）
「最後，號誌故障。系統建議派員前往指揮，並提供替代方案。」

### What-if 展示（1 分鐘）
「我們的系統還支援 What-if 模擬。指揮官可以輸入假設性問題，系統會立即回答應觸發的 SOP 條款。」

### 結語（30 秒）
「以上是我們的 Demo。我們的系統結合了決定性程式碼的可靠性與 AI 的靈活性，確保指揮官能在 60 秒內做出可靠決策。謝謝。」
